# Power-BI-Portfolio

🚀 Professional Power BI Portfolio and Analytics Hub. Featuring end-to-end BI solutions across healthcare and enterprise analytics. Includes Interactive Dashboards, Advanced DAX Modelling, and synthetic datasets hosted for live cloud-refresh.

---

## 🛠 Featured Analytics Projects

### 🏥 Healthcare Operational & Patient Outcome Analytics
* **Overview:** End-to-end clinical and operational dashboard analyzing hospital bed capacity, ER triage performance, 30-day readmissions, and patient length of stay (LOS).
* **Tech Stack:** Power BI, Advanced DAX, Python (Data Generation), Star Schema Modeling, Power BI Service.
* **Key Insights:** Identified high-risk readmission cohorts, optimized bed turnaround times by department, and calculated dynamic operational cost efficiencies.

---

## 🏗 Repository Architecture & Data Flow

1. **Synthetic Data Pipeline:** Custom Python scripts generating relational, business-logic-aligned CSV/SQL datasets.
2. **Data Modeling:** Optimized Star Schema models enforcing 1-to-many single-direction relationships and dedicated measure tables (`_Measures`).
3. **Dashboard Design:** Responsive, accessible layout adhering to modern UI/UX design principles with custom theme palettes.
